# Книги: раздел «Бібліотека»

Решение принято 2026-11-07. Статус: реализовано по TDD, 61 тест в `prod_tests/test_m_books.py`; весь набор проекта зелёный на SQLite и MySQL 8 (1275 тестов).

## Задача

Редактор добавляет книгу так же, как статью: заголовок, краткое описание, обложка. На странице книги
есть аннотация и кнопка (или несколько) для скачивания прикреплённых PDF.

## Как сейчас публикуются статьи (кратко)

`/publish` → `parse_article_form` (проверка полей, `sanitize_html`, `validate_image`) → `Article.save()`
(slug через `save_with_unique_slug`) → файлы в Cloudinary (`MediaCloudinaryStorage`, только изображения).
Статьи выбираются примерно в десяти местах (главная, «Всі статті», категории, автор, поиск, RSS, sitemap,
рекомендованные, кабинет), везде через `Article.objects.public()`.

## Решение: отдельные модели `Book` и `BookFile`

Не «статья с флагом» и не «PDF к статье в категории»: книги не должны попадать в ленты, RSS и поиск статей,
а у книги другие поля (автор книги, краткое описание, файлы). Всё остальное переиспользуется:
`save_with_unique_slug`, `safe_image_url`, `validate_image`, `sanitize_html`, `page_meta`, `editor_required`,
`is_repeat`, `STORAGE_ERRORS`.

| Модель | Поля |
|---|---|
| `Book` | `id` (UUID), `title`, `slug` (уникальный, транслит), `book_author` (текст), `summary` (до 400 символов, карточка и meta description), `annotation` (HTML, через `sanitize_html`), `cover`, `language` (`ua`/`en`), `is_published`, `created_at` |
| `BookFile` | `id` (UUID, как у остальных моделей: ссылки на файлы нельзя перебрать числами), `book` (FK, CASCADE), `file`, `label`, `size`, `downloads`, `order` |

Решения по открытым вопросам (выбраны рекомендованные варианты, меняются без переделки схемы):

- книги только в «Бібліотеці», не на главной и не в RSS;
- автор книги — свободный текст;
- комментариев у книги нет;
- язык: отдельная запись на каждый язык, как у статей;
- публикация без отложенной даты: `is_published` достаточно.

## Адреса

| URL | Что |
|---|---|
| `/books` | список опубликованных книг текущего языка, пагинация |
| `/books/<slug>/` | страница книги: обложка, название, автор, аннотация, кнопки скачивания с размером |
| `/books/<slug>/download/<uuid файла>/` | редирект на файл, +1 к `downloads`; 404 для неопубликованной книги |
| `/editor-cabinet/books/` | список книг и форма создания |
| `/editor-cabinet/books/<slug>/edit/` | редактирование, добавление и удаление PDF |
| `/editor-cabinet/books/<slug>/delete/` | удаление (POST) |

Обложка необязательна: без неё показывается статическая заглушка (`img/card-example.png`).

Неопубликованная книга видна редактору как предпросмотр (так же, как статья), остальным — 404.

## Хранение PDF

- Отдельный алиас `STORAGES['books']`: в проде `RawMediaCloudinaryStorage` (тип `raw`), в тестах
  `FileSystemStorage`. Поле: `FileField(storage=book_storage)`, где `book_storage()` возвращает
  `storages['books']`.
- `validate_pdf` (рядом с `validate_image`): расширение `.pdf`, начало файла `%PDF-`, размер не больше
  `BOOK_MAX_FILE_BYTES` (по умолчанию 20 МБ), не пустой. Имя файла заменяется на `<slug>-<uuid8>.pdf`.
- Размер в байтах сохраняется при загрузке (`BookFile.size`), чтобы не обращаться к Cloudinary при показе.
- Скачивание идёт через свой адрес: постоянная ссылка, проверка публикации, счётчик.

### Что проверить в Cloudinary (из кода это проверить нельзя)

1. Лимит размера файла тарифа (на бесплатном около 10 МБ). При необходимости уменьшить `BOOK_MAX_FILE_BYTES`.
2. Настройка «Allow delivery of PDF and ZIP files» в Security: по умолчанию выключена. Если она касается
   `raw`-файлов, скачивание вернёт ошибку. Проверить одной тестовой загрузкой.
3. Тайм-аут gunicorn 30 с: файлы до 10–20 МБ через сервер проходят. Для больших нужна загрузка из браузера
   напрямую в Cloudinary (отдельный этап, здесь не делается).

## Также затрагивается

Меню (`base.html`): пункт «Бібліотека». Sitemap: `BookSitemap`. SEO: `page_meta` с обложкой и описанием.
Переводы: `locale/`. `robots.txt` — без изменений (публичные страницы индексируются).

## План (TDD, по циклу на каждый пункт)

1. Модели и миграция, slug.
2. `validate_pdf`.
3. Публичные страницы: список, страница книги, фильтр по языку, предпросмотр.
4. Скачивание: редирект, счётчик, 404.
5. Кабинет: создание, редактирование, удаление, права.
6. Меню, sitemap, SEO.
7. Прогон всего набора на SQLite и MySQL.

## Известные ограничения

- Удаление книги или отдельного PDF убирает запись в БД, но не сам файл в Cloudinary (так же ведут себя
  обложки статей). Файлы остаются как «сироты»; чистить вручную или отдельной задачей.
- Если загрузка нескольких файлов падает на середине, запись в БД откатывается, а уже загруженные файлы
  остаются в хранилище.
- Загрузка идёт через сервер (лимит 30 с у gunicorn). Для файлов больше 20 МБ нужна прямая загрузка в Cloudinary.
